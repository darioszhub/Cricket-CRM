# Cricket CRM

Applicazione CRM sviluppata con **Laravel**, **Vue.js** e **Inertia.js**.

Il progetto nasce con l'obiettivo di realizzare un sistema CRM per la gestione di clienti, ordini, operatori, chiamate e attività correlate.

## Tecnologie

* PHP
* Laravel
* Vue.js
* Inertia.js
* Vite
* Tailwind CSS
* Eloquent ORM
* Microsoft SQL Server

## Funzionalità

Il progetto è attualmente in sviluppo.

Tra le funzionalità previste e in fase di implementazione:

* Autenticazione degli utenti
* Gestione utenti e operatori
* Gestione clienti
* Gestione ordini
* Gestione dettagli degli ordini
* Gestione chiamate
* Gestione stati e configurazioni
* Gestione gruppi e portafogli
* Funzioni di ricerca e filtraggio
* Interfaccia web tramite Vue.js e Inertia.js

## Stato del progetto

🚧 **In sviluppo**

Il progetto viene sviluppato progressivamente, con l'obiettivo di portare in Laravel le funzionalità del precedente sistema CRM e successivamente evolverne l'architettura.

## Database

Attualmente l'applicazione utilizza un database Microsoft SQL Server esistente.

I modelli Eloquent presenti nel progetto rappresentano le entità utilizzate dall'applicazione e le relative relazioni.

In una fase successiva è prevista la migrazione verso una struttura database gestita direttamente tramite **Laravel Migrations**.

## Struttura del progetto

La logica principale dell'applicazione è organizzata secondo la struttura standard di Laravel:

* `app/Models` — modelli Eloquent
* `app/Http/Controllers` — controller
* `resources/js` — componenti e pagine Vue.js
* `resources/views` — viste Blade
* `routes` — definizione delle rotte
* `tests` — test automatici
